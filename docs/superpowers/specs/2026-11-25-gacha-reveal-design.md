# ガチャ演出の強化（短い設計書）

日付: 2026-11-25 / 依頼: 会長

## 目的
いまのガチャは、引くとすぐ結果一覧が出るだけで「ゲームっぽさ」が足りない。
引く前のドキドキ、1体ずつの登場、初めて出たキャラの特別演出を足して、引くこと自体を楽しくする。
ガチャはストーリー『福井めぐり』クリア後のご褒美なので、最初の一回が特に印象に残るようにしたい。

## やること（会長が決めたこと）
- 引く前にタメの演出を入れる
- 1体ずつ出てくるようにする
- 初めて出たキャラには特別な演出を入れる
- 作り方は案A（ゲーム内で全部作る。動画は使わない）

## 流れ（提案、こちらの判断）
1. **タメ（約2秒）**: 暗転 → のれんの奥でそば釜が湯気を上げて光る。光の色は今回の最高レア度で決まる
   （N/R=青白、SR=紫、SSR=金＋画面が揺れる）。SR以上のとき、たまに途中で色が格上げされる演出
   （例：青→金）を入れる。タップで早送り可。
2. **1体ずつ登場**: カードが裏向きで出て、タップでめくる。レア度の色の光と効果音。
   右上に「スキップ」。押すと残りを飛ばして一覧へ。
3. **初登場キャラの特別演出**（サーバー結果で `dup` が false のもの＝今の「NEW!」）:
   画面いっぱいにキャラ絵、名前が大きく入り、セリフ（quote）を表示、「NEW!」の判子。
   SSRの初登場はさらに後光と紙吹雪。タップで次へ。
4. **一覧**: 今と同じ結果画面（かぶり🌾+、NEW!表示）。

## 作り方（案A）
- index.html の `showGachaResult` の前に演出シーンを挟む。演出用の要素とCSSアニメーションを追加。
- 効果音は WebAudio でその場で合成（タメの上昇音、めくり音、SR/SSR用の鐘）。新しい音声ファイルは足さない。
  既存の `audioContext` を使う。
- キャラ絵は既存の `chars/*.webp`、セリフは `CHARACTERS[id].quote` / `quoteEn`。日英両対応。
- `prefers-reduced-motion` のときは揺れ・紙吹雪を止める。

## 検討した案
- **A. ゲーム内で全部作る（採用）**: 軽く、どの端末でもすぐ動く。16体すべて同品質。
- B. 初登場時に紹介動画を流す: 豪華だが1本5〜8MBで、スマホでは待ち時間がドキドキを途切れさせる。
- C. A＋「紹介動画を見る」ボタン: 動画の置き場所が要る。Aのあとで足せるので後回し。

## やらないこと
- 確率・そば粉・サーバー（gas/Code.gs）の変更
- 紹介動画の組み込み

## 失敗とみなすこと
- 毎回長くて面倒になる（→タップ早送りとスキップ必須）
- 演出の色とレア度が食い違う（結果はサーバーの値だけで決める）
- 通信待ちの間に何も起きない（→タメ演出は通信中から始め、結果が来てから色を決める）

## 作り手に任せること
細かい秒数、色味、効果音の音色、レイアウトの微調整。
